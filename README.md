# Relicario — descargas

Instaladores de **Relicario** para Windows. El código no está aquí.

Descarga la última versión en [Releases](https://github.com/AlexSubx/Relicario-descargas/releases/latest): `Relicario-Setup-X.Y.Z.exe` (instalador) o el `.zip` (sin instalar).

Al abrirse, Relicario avisa cuando hay una versión nueva.
